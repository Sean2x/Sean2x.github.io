Each dotted ring is the equator of the axis with its color: x′ red, y′ green, z′ blue. The big red dot is the nose, where x′ meets the ball (faded when it is on the far side).

Notes: what we learned

  1. Rotations don't commute. 90° about x then 90° about y is not the same as y then x. Take the point (0, 0, 1): x then y ends at (0, −1, 0); y then x ends at (1, 0, 0). In matrices, Ry·Rx ≠ Rx·Ry. Only turns about the same axis, or tiny angles, commute.
  2. Fixed axes vs body (moving) axes. The same angles in the same order give different orientations. A sequence about the moving axes equals the reverse sequence about the fixed axes: yaw ψ about z, pitch θ about the new y′, roll φ about the new x″ equals roll φ about fixed x, pitch θ about fixed y, yaw ψ about fixed z.
  3. What aircraft use. Flight dynamics uses body axes, yaw-pitch-roll (3-2-1): yaw ψ about the vehicle z (down), then pitch θ about the new y, then roll φ about the new x, with vbody = L3·L2·L1·vvehicle. That is the default Aircraft mode, and it is exactly the class matrices below. The same attitude can also be built as turns about the fixed axes in the reverse order: roll about the fixed x, then pitch about the fixed y, then yaw about the fixed z. (Doing yaw, pitch, roll about the fixed axes with the same numbers would give a different orientation, and is not what aircraft use.)
  4. Which axis a slider spins about. In a product of three rotation matrices, the leftmost factor acts about a fixed axis, the rightmost about the ball's own axis, and the middle one about something in between. In the Aircraft mode (R = Rz(ψ)·Ry(θ)·Rx(φ)), yaw spins the whole ball about the vehicle z, roll spins it about its own nose axis x′, and pitch spins it about the y axis after the yaw. With absolute angles you can't make all three sliders spin about the ball's own axes, which is why Body rotations mode exists: every drag is a small turn about the ball's current x′, y′ or z′, so it remembers the order you moved things in.
  5. Class-notes convention (passive, column vectors, body axes). v1 = L1(ψ)v, v2 = L2(θ)v1, v3 = L3(φ)v2, so v3 = L3·L2·L1·v. These re-express a vector's components in the turned axes. These are the matrices shown in Aircraft mode. Matrices that move the vector itself (active) are their transposes, applied in the opposite order.
  6. Turning about several axes at once. Any rotation is a single turn about one tilted axis (Euler's rotation theorem). Angular velocities add as vectors, but Euler-angle rates don't map one-to-one onto x, y, z. For yaw-pitch-roll the body-frame rates are p = φ̇ − ψ̇ sθ, q = θ̇ cφ + ψ̇ sφ cθ, r = −θ̇ sφ + ψ̇ cφ cθ. At pitch θ = ±90° the yaw and roll axes line up (gimbal lock) and those formulas blow up, which is why quaternions are used instead.
  7. How many conventions. 12 axis orders (6 like yaw-pitch-roll with three different axes, 6 like z-x-z with a repeated axis) × fixed or body = 24, but each fixed convention equals a body one in reverse order, so there are 12 distinct rotation formulas. Active vs passive, row vs column vectors, angle sign and handedness change the notation, not the ball.
  8. Frames and names. The vehicle frame has its origin at the vehicle's center but its axes never turn: x north, y east, z down (the direction gravity pulls). The body frame is attached to the vehicle: x out the nose, y out the right wing, z down through the belly (not up). Both are right-handed. In the class sequence, v1 is in the vehicle-1 frame (after the yaw), v2 in the vehicle-2 frame (after the pitch), and v3 in the body frame (after the roll). On this page the grey axes are the vehicle frame and the colored x′, y′, z′ are the body frame.
  9. Gravity in each frame. In the vehicle frame gravity is (0, 0, g). In the body frame it is L3·L2·L1·(0, 0, g) = g·(−sθ, sφcθ, cφcθ). Level flight (θ = 0, φ = 0) puts all of it on body z; pitching the nose up puts part of it on −x, and banking puts part on y. An accelerometer measures exactly this, which is how an aircraft finds its pitch and roll. The picture on this page uses the aerospace layout: x (nose / north) to the right, z (down / gravity) down the screen, and y (right wing / east) toward you, so a positive pitch lifts the nose.
